# n8n AI Email Automation – Subject and Body Extraction

## Overview

This project demonstrates how to use **n8n, an AI Agent, a JavaScript Code node, and Gmail** to automate email processing.

The workflow receives email-related content from an AI Agent, separates the email subject from its body using JavaScript, and prepares the resulting fields for mapping into a Gmail Send node.

The goal is to transform unstructured AI-generated email text into structured fields that can be used in an automated email workflow.

## Objectives

- Process email content generated by an AI Agent.
- Extract the email subject from the generated text.
- Separate the subject from the email body.
- Prepare structured output for the Gmail Send node.
- Reduce manual email preparation.
- Demonstrate how AI and JavaScript can work together in an n8n automation workflow.

## Workflow Architecture

```text
Gmail Trigger
     |
     v
Edit Fields
     |
     v
AI Agent
     |
     v
Code in JavaScript
     |
     v
Gmail Send
     |
     v
Email Delivered
```

**Workflow components**

1. **Gmail Trigger:** Initiates the workflow when an email event matching the configured trigger occurs.
2. **Edit Fields:** Prepares or maps the input data required by the AI Agent.
3. **AI Agent:** Generates the email content based on the instructions and available context.
4. **Code in JavaScript:** Extracts the subject and body into separate JSON fields.
5. **Gmail Send:** Uses the structured fields to send the email.

The Gmail Send node must be configured with valid recipient information and Gmail credentials.

## JavaScript Code Node

The Code node processes the AI Agent output and separates the subject and body.

```javascript
const items = $input.all();

return items.map(item => {
  // Get the email generated by the AI Agent
  const emailText = item.json.output || "";

  // Extract the subject
  const subjectMatch = emailText.match(/^Subject:\\s*(.+)$/im);

  const subject = subjectMatch
    ? subjectMatch[1].trim()
    : "Follow-up from AfriFizz AI Receptionist";

  // Remove the subject line from the body
  let body = emailText
    .replace(/^Subject:\\s*.+\\r?\\n?/im, "")
    .trim();

  // Remove optional Markdown code fences
  body = body
    .replace(/^```(?:text|markdown)?\\s*/i, "")
    .replace(/\\s*```$/, "")
    .trim();

  return {
    json: {
      subject,
      body
    }
  };
});
```

### How the code works

1. Retrieves all input items from the previous node.
2. Reads the AI Agent response from `item.json.output`.
3. Searches for a line beginning with `Subject:`.
4. Extracts the subject text.
5. Removes the subject line from the email body.
6. Removes optional Markdown code fences.
7. Returns the subject and body as separate JSON fields.

**Important:** The AI Agent must generate a subject line beginning with `Subject:` for the extraction to work as intended.

## Example Input

```text
Subject: Re: Invitation to edit "AfriFizz_AI_Receptionist_Dummy_Data"

Hi Moses,

## Gmail Send Node Configuration

After executing the Code node, map the output fields into the Gmail Send node.

| Gmail field | n8n expression |
|---|---|
| To | `{{$json.to}}` |
| Subject | `{{$json.subject}}` |
| Email format | Text |
| Message / Body | `{{$json.body}}` |

The `to` field must be available from an earlier node or explicitly preserved in the Code node output. The sample code above returns only `subject` and `body`.

If the recipient is stored in the incoming item, modify the return object to include it:

```javascript
return {
  json: {
    to: item.json.to,
    subject,
    body
  }
};
```

If the recipient is stored in a different node, map it from that node using the appropriate n8n expression.

## Setup Instructions

### Prerequisites

- An n8n instance, either cloud-hosted or self-hosted.
- An AI model configured for the AI Agent node.
- Gmail credentials configured in n8n.
- A Gmail Trigger and Gmail Send node configured for the intended workflow.

### Implementation

1. Create a new workflow in n8n.
2. Add and configure a Gmail Trigger.
3. Add an Edit Fields node if you need to prepare the email context.
4. Add an AI Agent and configure its system instructions.
5. Instruct the AI Agent to generate email content with a clearly labelled `Subject:` line.
6. Connect a Code node after the AI Agent.
7. Set the Code node language to JavaScript.
8. Select **Run Once for All Items** or another suitable execution mode for your implementation. The provided code uses `$input.all()` and processes every incoming item.
9. Paste the JavaScript code into the Code node.
10. Execute the Code node and confirm that the output contains `subject` and `body`.
11. Connect the Code node to the Gmail Send node.
12. Map the recipient, subject, and body fields.
13. Test the workflow using a controlled email account before enabling it for regular use.

## Limitations and Future Improvements

### Current limitations

- The code expects the AI Agent response to be stored in `item.json.output`.
- The subject must use the `Subject:` prefix.
- The fallback subject does not guarantee that the email is appropriate to send.
- The code does not validate recipient addresses.
- It does not independently verify the AI-generated content or prevent duplicate sends.

### Potential improvements

- Configure the AI Agent to return structured JSON with separate `subject` and `body` fields.
- Add input validation and error handling.
- Preserve the original recipient and relevant email metadata.
- Add an approval step before sending sensitive or external emails.
- Add logging and error notifications.
- Implement retry handling and duplicate-send protection where appropriate.
- Add email classification and routing for different business processes.

## Security and Privacy

- Store Gmail credentials using n8n credentials rather than hardcoding them in JavaScript.
- Avoid logging confidential email content unnecessarily.
- Restrict access to workflow executions and stored execution data.
- Validate recipients before sending emails.
- Use human approval for sensitive, high-impact, or externally directed communications.
- Follow applicable organizational email security and data protection requirements.
